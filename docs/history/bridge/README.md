# MCP Bridge history (unsupported)

These documents describe Lattice Relay's predecessor, MCP Bridge (`obsidian-mcp-bridge`, last version 2.0.0), and its Node (`obsidian-mcp-server-node` 1.0.0) and Python servers. They are kept as historical evidence of design decisions and testing. They are **not** current instructions, and the setups they describe are not supported.

For current documentation start at the [README](../../../README.md). To move a vault from Bridge to Relay, see [Upgrade from MCP Bridge](../../guides/upgrade-from-bridge.md).

The retired Python servers (`servers/python/`, `test_connection.py`) were removed from the tree in Relay 0.1.0 and remain in Git history.
